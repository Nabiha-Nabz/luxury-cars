# Luxury Motors Showcase

Luxury Motors is a responsive automotive showcase concept featuring a branded landing page, vehicle showroom, and customer contact experience.

> **Client project:** This concept was created for a client to demonstrate how a premium automotive brand could be presented online. It is published as a portfolio and project-delivery reference.

## Features

- Premium automotive landing page
- Multi-brand vehicle showroom
- Responsive contact page
- Custom transitions and visual effects
- Original design mockups included for reference

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No build tools are required.

```bash
git clone https://github.com/Nabiha-Nabz/luxury-cars.git
cd luxury-cars
python -m http.server 8000
```

Open `http://localhost:8000` in a browser.
